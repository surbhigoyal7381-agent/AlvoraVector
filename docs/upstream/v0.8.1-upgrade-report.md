# Fleetbase v0.8.1 upgrade report

Date: 19 Nov 2026 · From v0.8.0 (on `dev`) to v0.8.1 (upstream tag `v0.8.1`, commit 022238c5)

## What changes

A patch and dependency release. There are no configuration or environment changes.

| Component | v0.8.0 | v0.8.1 | What it brings |
|---|---|---|---|
| core-api | 2.0.0 | 2.0.2 | Migrations run on MySQL 8.4; extensions can register sort keys (`Model::addSortHandler`) |
| fleetops / fleetops-engine | 0.7.0 | 0.7.1 | The adhoc dispatch migration finishes on MySQL 8.4 and after a failed run |
| ember-core | 0.3.26 | 0.3.27 | `TableColumn.withSort / inGroup / hiddenByDefault` for extension columns |
| ember-ui | 0.4.6 | 0.4.7 | Column groups in Customize Columns |
| docker/Dockerfile | — | — | Retries the PHP extension install when PECL or apt fails |

## Effect on AlvoraVector

- **Merge:** clean, no conflicts. `dev` had no changes of ours in the touched files.
- **Database:** our stack uses MySQL 8.0, which was never affected. `php artisan migrate` has nothing new to run.
- **Our extensions (future):** the new column hooks let an Alvora extension add sortable, grouped columns to Fleet-Ops tables without changing Fleet-Ops. This keeps us on rung 3 of the ladder instead of rung 5.
- **ERPNext connector:** no API changes. Not affected.

## Tests (local, 19 Nov 2026)

- API shell: 44/44 pass.
- Console: lint is clean and 1,446/1,446 Ember tests pass (Node 22, Chrome).

## Upgrade steps

1. Pull the new API image, then restart application, queue and scheduler.
2. Rebuild the console.
3. Run `php artisan migrate` and `php artisan sandbox:migrate`.

## Recommendation

Take v0.8.1 into `dev`. The risk is low.
